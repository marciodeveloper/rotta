# ROTTA — pessoas, lugares e histórias em movimento

Plataforma híbrida de descoberta, experiências, conteúdo audiovisual, negócios locais e marketplace.

## Estado do projeto

O repositório começa intencionalmente vazio. A primeira entrega será um protótipo visual responsivo, estático e navegável, com dados demonstrativos. Não representa ainda uma plataforma transacional nem possui backend, autenticação ou checkout real.

## Direção de marca

- Grafite e carvão como base editorial.
- Verde-petróleo como campo institucional.
- Marfim para leitura e contraste.
- Cobre/dourado queimado para acentos e ícones.
- Fotografia de experiências e destinos: pessoas vivendo o lugar, não equipes de reportagem.
- Assinatura: **Pessoas, lugares e histórias em movimento.**

## Desenvolvimento

A primeira fase usa HTML, CSS e JavaScript sem dependências, para facilitar publicação no GitHub Pages e evolução gradual do produto.
